~~Dijkstra's Algorithm~~

Dijkstra's algorithm finds the shortest paths from a source node to all other nodes in a graph with non-negative edge weights. It maintains a set of visited nodes and continuously expands the shortest-path frontier.

[G]{"type": "graph", "nodes": [["S", 100, 80], ["A", 200, 40], ["B", 200, 120], ["C", 300, 40], ["D", 300, 120]], "edges": [["S", "A", "2"], ["S", "B", "6"], ["A", "B", "3"], ["A", "C", "1"], ["B", "D", "5"], ["C", "D", "2"]]}[/G]

**Algorithm Steps (using a Min-Priority Queue):**

1. Initialize: Set distance to source = 0, all others = ∞.
2. Push (0, source) into the PQ.
3. Pop the node `u` with the minimum distance. If `u` is already visited, skip.
4. Relaxation: For each neighbor `v` of `u`, if `dist[u] + w(u, v) < dist[v]`:
   - Update `dist[v] = dist[u] + w(u, v)`
   - Push `(dist[v], v)` into the PQ.
5. Mark `u` as visited. Repeat until PQ is empty.

**Trace Through the Example:**

- **Pop S:** Visit S. Relax S->A (0+2 < ∞) and S->B (0+6 < ∞). PQ has (2, A), (6, B).
- **Pop A:** Visit A. Relax A->B (2+3=5 < 6) and A->C (2+1=3 < ∞). PQ has (3, C), (5, B), (6, B).
- **Pop C:** Visit C. Relax C->D (3+2=5 < ∞). PQ has (5, B), (5, D), (6, B).
- **Pop B:** Visit B. Relax B->D (5+5=10 > 5). No update. PQ has (5, D), (6, B).
- **Pop D:** Visit D. PQ has (6, B).
- **Pop B:** B already visited, skip.

**Final Shortest Paths from S:**

- S -> A: 2
- S -> B: 5 (Path: S -> A -> B)
- S -> C: 3 (Path: S -> A -> C)
- S -> D: 5 (Path: S -> A -> C -> D)

**Limitation:**

Dijkstra's algorithm fails with negative edge weights. It assumes that once a node is popped from the PQ, its shortest path is permanently found. A negative weight could later provide a shortcut to an already visited node, violating this greedy assumption.

[B]Greedy + Relaxation = Optimal for non-negative weights[/B]
