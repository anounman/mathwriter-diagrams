~~System Capabilities Summary~~

The DRAW engine supports 16 primitives with 5 line styles:

| Primitive | Purpose |
|-----------|---------|
| LINE | Straight lines, axes, connectors |
| CURVE | Quadratic bezier curves |
| CUBIC | Cubic bezier curves |
| RECT | Boxes, memory cells, nodes |
| CIRCLE | Tree/graph nodes, sets |
| ELLIPSE | Oval shapes |
| ARROW | Directed edges, pointers, flow |
| PATH | Multi-point open paths |
| POLYGON | Diamonds, triangles, closed shapes |
| ARC | Circular arcs, pie slices |
| GRID | Tables, matrices, arrays |
| TEXT | Labels, values, annotations |
| DOT | Points, markers, filled nodes |
| BRACKET | Parentheses, grouping |
| BRACE | Curly braces, set notation |
| HIGHLIGHT | Emphasis, cell highlighting |

Line styles: wobbly (default), smooth, dashed, rough, thick.

The engine can draw ANY computer science diagram — trees, graphs, arrays,
linked lists, stacks, queues, heaps, hash tables, flowcharts, state machines,
memory layouts, number lines, Venn diagrams, coordinate planes, function plots,
tries, expression trees, DP tables, and more. All in hand-drawn Apple Pencil
blue ink style.
